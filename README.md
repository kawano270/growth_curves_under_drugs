This repository contains a Python-based Jupyter Notebook designed for a data paper to process bacterial growth curve data. The script calculates key growth parameters—such as lag time, maximum growth rate, and maximum optical density (OD)—from time-series OD600 measurements. It first loads the time-series data, devided into two separate Excel files due to the large dataset size, and calculates parameters for each individual growth curve. The extracted parameters are then merged with media condition data, followed by an outlier analysis using the Smirnov-Grubbs test across replicates under identical media conditions to assign reliability flags.
